# MANN STORE

Boutique de smartphones à Douala, Cameroun — iPhone, Samsung Galaxy et Google Pixel.

Site statique : aucune étape de build. Vercel sert les fichiers tels quels.

- `index.html` — la boutique complète (catalogue, panier, commande WhatsApp)
- `assets/products/` — photos réelles du stock
- `assets/brand/` — logo, favicon, image de partage
- `vercel.json` — cache et en-têtes de sécurité

En ligne : https://mann-store-six.vercel.app
